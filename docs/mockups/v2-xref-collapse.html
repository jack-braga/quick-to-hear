Cross-reference collapse

The decided model: no standalone “Support passage” card. A reference to another passage is only an @-mention inside a note, carrying two inline toggles. Flip Include for the group to see the print change.

In the study — a note with an @-mention

Include for the group Prep-only — you peek here; the group never sees it. Turn on to print the passage in the handout + leader’s notes.
↩ Return question The follow-up that steers the group back to the main passage after you send them here.
Replaces the old flow: a mention’s peek had a ⤴ Promote to support passage button that spawned a separate Support-passage card. Now the mention is the object — the toggles live on it, so there’s one thing to manage, not two.
