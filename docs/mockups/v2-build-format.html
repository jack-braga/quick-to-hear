Build — format settings + spacer blocks

Two additions to the Build lens: a Font size control (per-study) and insertable spacer blocks of variable size. Both flow through the same export preview, so the on-screen preview, the print, and the PDF all match. The Aa size + Ink-saver sit in the settings bar; a spacer is a draggable block in the running order that prints as blank space (no rule).

Font size (S / M / L, per-study) scales the whole document — passage, questions, notes — via one style on the export root, so preview + print + PDF stay identical. Spacer is a draggable block in the running order with a variable size (a “lines” stepper, or drag a handle); it prints as that much blank space with no visible rule — the dashed guide + label only show here in the on-screen preview so you can grab and resize it. Spacers appear in both the participant and leader documents (they’re layout).
